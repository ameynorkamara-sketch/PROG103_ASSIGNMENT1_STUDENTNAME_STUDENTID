## Project Overview
This is a terminal-based Python application that manages student academic records.
It was developed as Assignment 1 for PROG103 and solves a real-world problem
in education by allowing users to add, view, and manage student results.

---

## Features
- Add student records with scores for 5 subjects
- View all students in a formatted table
- View individual student report with grade and pass/fail status
- Delete student records
- View class summary with statistics
